05. Introduce my assistant: ChatGPT

How I adapt ChatGPT into my daily life and classify tasks to maximize productivity without losing my edge.

Ngan Ho · March 15, 2024 · 5 min read

From its first launch in November 2022, people all over the world are excited about ChatGPT, and everyone is impressed by its ability to handle a wide range of tasks, from writing paragraphs and emails to coding and analyzing data. It’s gaining popularity for its versatility in tackling both basic and advanced tasks effortlessly. Today I want to share with you about how I adapt its usage with my daily life tasks.

So, what is ChatGPT?

ChatGPT is a chatbot developed by OpenAI, using the GPT model to “continue” writing based on the input you provided. It means, you can ask questions, and based on the words in your question, the language model (LLM) under will generate the “suppose-to-be” answer for your question. This language model is trained with vast amount of text and content on Internet, so it can be very good at answering your problems.

How ChatGPT can be used with your daily tasks?

In my company, ChatGPT is a hot topic of discussion. Everyone seems to love it, and we’ve even made it our go-to virtual assistant for many of our daily tasks. It’s been a game-changer, boosting our productivity by handling repetitive tasks that we find a bit dull and also accelerating our skill development in various areas.

But honestly, in my opinion, if we ask ChatGPT to handle every single task, then, what is the value you bring to the table? So, I tried to be careful and classify the type of tasks where I can freely use ChatGPT and where shouldn’t I.

Here is 3 groups of tasks that I consider using ChatGPT and for each specific task in each group, I will provide you the example why I applied different level of usage of ChatGPT (But let take simple assumption here, that there is no task will violate the data privacy within these 3 groups):

Group 1

The first group of tasks involves those where I aim to enhance my skills while completing them. There’s no rush to finish quickly, and I have the ability to validate the results given by ChatGPT along the way.

Then, what I have done is: I would start on looking at the whole picture of the task, from the high-level picture to detailed puzzle. Then, I would learn as normal, step by step, and I use ChatGPT as my intelligent classmate, whom I can discuss what I learn with, also ask him (or her or them, whatever it would like to call 😉) to hear their answers for my confusion point. Because in this case, I want to develop my own skills/ability and also my critical thinking, so I don’t want ChatGPT to do everything for me.

One example for that is I create the charts using highcharts-python package in Python. The document is quite long, so I decided to ask ChatGPT to summarize it and also, ask it the point where I need to clarify to help me understand all the arguments of the highcharts function easier.

One point noted on that, because ChatGPT is using the training data to January 2022, while the highcharts-python is just created and developed recently, so when I want ChatGPT to help, I need to provide it more updated documents.

  • I input the highcharts-python document into ChatGPT.
  • It showed me the example how can I use it and the explanation
  • It answered my question. And in this point, it also helps to correct the last reply from ChatGPT, that’s why you should have the ability to validate the answer to make sure ChatGPT is not creating something wrong and provide it to you.

Group 2

The second group of tasks would be the tasks where I don’t want to develop my skills during working on these tasks, while I need to finish it in a short amount of time. Also, I have the ability of validating the output from ChatGPT.

So, my behavior in these tasks is I will try to use ChatGPT as much as possible, while I only need to learn about the concept, the rule of how it works behind. To be honest, I tried too much not to just finish while I don’t know anything about what I’ve done, because I’m kind of person who feels uncomfortable for being not knowing anything. But then, I realized that I could make myself balance between the feelings and make myself accept that I could lose some control over my tasks, to make it quick and finish just deliver to my boss.

The example of this task is there was one day, my boss wants to have this KPIs boxes in our tool. The tool is programmed in Python, however, if you want to create these boxes, it needs to be done using HTML and CSS, and I need to complete the tasks in 3 days, so it is not possible for me to learn everything about HTML, CSS and also how to embed it inside a Python tool. In this case, ChatGPT really helps me to finish the tasks. It helps to create the structure for the boxes, then based on my desire, I would refine the boxes for better look.

This is an example how I can use ChatGPT for this task (We will need to refine the code many times in reality to actually achieve the final result, but again, it still took shorter time than if you learn HTML to code yourself).

Group 3

This is the group for tasks where I want to develop my skills in, however, I don’t have enough knowledge or experience to validate the result. In this case, I need to be very careful because I cannot trust and use ChatGPT output completely like two groups above.

An example of this situation is, one time when we develop Streamlit app, we don’t want to use multiselect default widget, because with every option, it will expand the area for selection, not very user-friendly UI. So we want to bring the widget from other language: TypeScript into our app.

However, the problem is, because I don’t have any knowledge about TypeScript, while developing this widget, we just tried copying the code from Internet, setup locally and then ask ChatGPT to help modify as we needed. The result is really exhausted because we cannot control the output, just accept everything ChatGPT gave us, and most of the response from ChatGPT didn’t meet our expectations. 😮‍💨

Conclusion

  • ChatGPT is really helpful for us to save time on repetitive tasks, increase our productivity so we can focus on other activities in our life.
  • But be careful with the tasks where we can not validate the output, or be able to ask efficient questions for ChatGPT to provide right answers.
  • With the tasks we want to learn and develop our skills during working on these, we should not ask ChatGPT to do everything for us, because this will make us lose our thinking habit and lose opportunity to develop our critical thinking.
A great tool to have, as long as we use it as an assistant rather than a replacement. March 15, 2024
