04. It will work somehow in the future

A perspective about stepping out of my comfort zone with the belief that everything will “make sense” eventually.

Ngan Ho · February 24, 2024 · 3 min read

I once shared Steve Jobs' famous quote about "connecting the dots"—the idea that one day when we look back, the things we’ve done will connect and we will see that it finally makes sense. This concept ties closely into a mindset I have whenever I face something completely new:

“It will work somewhere, some day in the future”

In my life, I have relied heavily on this way of thinking to:

  1. Push myself out of my comfort zone to learn new things, even when I can't quite see their immediate application at the moment.
  2. Adjust my attitude when learning and practicing these things, finding the sweet spot between working to earn a living vs. pursuing a personal hobby.

One specific case this mindset to apply is when I work in a small team

Context of the story

If you have ever worked in a small company, you will quickly realize that you often have to tackle tasks that fall outside your official scope of work. Depending on the nature of those tasks and your personal career orientation, you might feel completely fine with it, or not ok at all.

My university major only included about 5% of subjects related to programming language concepts. Yet, in my role as an Analyst within a small consulting team, I ended up handling several developer tasks (to be fair, it wasn't advanced enough to land me a dev role at an IT firm, but it was certainly more advanced than what is typically expected from a data analyst working solely with dashboards).

One of these tasks was building an end-to-end web app using Streamlit. In short, it's a python-based web app that displays interactive dashboards and allows users to filter and visualize data. I'll write a more detailed documentation about it in a future document hehe.

When I first received this task, I felt a bit overwhelmed because it required a brand new skill set, and I had no idea how it would contribute to my personal development or career. But being a (trying-to-be) optimistic girl, I figured it was just like the philosophy of this blog: just do it, and the skill will come in handy when needed. And today, I actually ended up using that exact knowledge to adjust the styling format of this blog.

Just a quick counter-argument here: I don't think every out-of-scope task is automatically ok and fine. I'll save that topic for a separate discussion later down the road.

Example from my old blog

Problem

I use the Elementor plug-in in WordPress to display my latest posts on the website's homepage like this. Because the length of each post title is different, the display banners end up misaligned - which drives me crazy :v

When building the web app using Streamlit, I ran into the exact same problem where two structural layout blocks would not align. The great common denominator between Streamlit and Elementor is that both allow users to inject custom CSS to better format and polish the website. So, here is how I went about adjusting the CSS inside Elementor.

Instruction

  • In the widget editing mode, click on Advanced > Edit Widget HTML
  • Open the CSS tab in the editor screen; a widget is a collection of multiple internal items marked by CSS codes.
  • To find the CSS code of the outer border element that needs adjusting, go back to the blog page and press F12 to open the browser's developer tools. Click on the Select Element button, which allows you to hover over and click an element to reveal its CSS.
  • Adjust the CSS and observe the changes to that element until you achieve the desired outcome. For example, here I added height: 400px, and all elements are now perfectly aligned.
  • Since the CSS adjustments made in Dev mode will reset when you refresh the page, you need to add them to Elementor's Custom CSS to save your changes.
  • Abracadabra 💥 ~ Everything is beautiful now ~~

Conclusion:

  • There are some tasks we have to do right now without knowing what they are for, but one day, somewhere down the line, they will prove useful.
  • When we are young, don’t think too much before you start working and learning on something
  • But of course, under circumstances where time and resources are limited, we must balance and prioritize our tasks so we don't spread ourselves too thin or do things completely without direction.
