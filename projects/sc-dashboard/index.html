About the Project

This dashboard was built to give supply chain managers a real-time view of inventory levels, order fulfilment rates, and supplier performance — all in one place. Before this tool, reporting was done manually in Excel, which took hours each week.

The app connects directly to the data warehouse, applies business logic, and renders interactive charts so stakeholders can drill down without writing a single query.
